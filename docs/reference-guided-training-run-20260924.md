## 结论边界

这证明该小模型在封版数据的**离线理想 Root 条件**下学到了比简单保持/插值更准确的未来位置。它没有评估真实玩家控制、Root 规划误差、骨长、脚接触、旋转矩阵正交化、蒙皮、IK、碰撞或 UE 实时推理性能。来源语义变体可能跨非 Traversal 分区；测试改进不等于完全独立泛化或可直接接入游戏。最终检查点仍是研究用候选，不能当作已完成的运行时模型。
